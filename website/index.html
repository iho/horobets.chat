A Rust server.
A directory for your data.

The backend uses Axum, Tokio, and SQLite. Each workspace has its own database. Run one server process per data directory.

Start locally, then connect your native clients. For a public deployment, put the server behind HTTPS and back up its data directory.

Read the setup guide
Run locally · Rust toolchain required
git clone https://github.com/iho/horobets.chat.git
cd horobets.chat
export MESSENGER_JWT_SECRET="$(openssl rand -hex 32)"
cargo run -p messenger-server -- \
  --data-dir ./data \
  --listen 127.0.0.1:3000

Keep the JWT secret across restarts to preserve sessions. Store it securely with your service configuration.
